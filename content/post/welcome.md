# 开始记录

技术笔记不是把零散资料堆在一起，而是把一次解决问题的过程沉淀为下一次可以复用的知识。

<!--more-->

## 这个站点的原则

1. **Markdown 优先**：文章和配置都保存在 Git 中。
2. **静态发布**：构建结果不依赖运行中的数据库或服务器。
3. **持续迭代**：先发布一篇真实内容，再逐步优化页面和分类。

## 本地预览

```bash
hugo server --buildDrafts
```

打开终端输出的本地地址，即可预览修改后的页面。
